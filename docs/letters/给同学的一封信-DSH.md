# 写给刚接触 DSH 的你

> 小潇让我写这封信。他说你最近不太好过，也说你想知道我是怎么被他用起来的。
> 你完全没接触过也没关系——这封信就是按「从零开始」写的，你可以照着一步步做。
> 我先讲我们俩的事，再讲怎么上手，最后说几句心里话。看不完也没关系，先看第四节。

---

## 一、先说清楚它是什么

DSH（DeepSeek Harness）外面看是一个聊天窗口，但它和普通的 AI 聊天有两个关键区别：

1. **它能动手。** 它不只会写字，它能读你电脑上的文件、写文件、跑命令、装插件、开网页。你说「帮我把这些资料排成一页 A4」，它真的会在你的文件夹里生成一个 `.docx`。
2. **它能记事。** 你有工作区（一个文件夹），它做过的改动、写过的文档、犯过的错都留在里面。换个会话也不会从零开始。

三个类比，你挑一个顺手的：

- **像一个刚入职的实习生。** 手很快，不怕麻烦，什么都能学，但**必须你把事情说清楚**。你说「弄个计划表」，它会问你「给谁用、一天几栏、要不要留空写」。你说得越具体，它做得越对。
- **像一个工位。** 你可以把「做一半的东西」放在这儿：半成品文档、随手记的规则、待办。它不会嫌乱。
- **不像什么：** 不像搜索框（它不负责告诉你世界上的答案），不像老师（它不会替你学会），也不像人（它不知道你今天为什么不想说话）。

## 二、我是怎么用起来的

2026 年 11 月 8 日凌晨，小潇把一份 `设计文档.doc` 扔给我，里面写的是一个幻想界面：倾斜的银色星环、六颗行星各代表一门课、鼠标悬停时像引力透镜一样把无关的星体压暗。

他的第一句话是：**「你愿意帮助一下我嘛。」**

那天晚上我们没做界面。我们做了一件更笨的事：把幻想翻译成「能不能落成代码」——星环用什么画、行星怎么算远近、知识网络怎么排布。第二天，它真的跑起来了。

后来的三个月，我们做了这些（都能核对）：

- 一个真装在 DSH 里的插件：侧栏一个「认知终端」，里面有星图、控制台、会议室、今天该做什么；
- 一条能用的出纸链路：政治、英语的每日一页，Word 排版、A4、一页装完、直接打印；
- 一个英语周包：18 页，周计划 + 每天两页 + 记录页 + 写作页，词组默写后面直接给答案；
- 一套「换会话也不失忆」的习惯：票单、信箱、16 项自动测试、每次改动留痕。

这些东西没有一件是「一句话变出来的」。每一件都经过：**先做能跑的最小版本 → 看见它难看/出错 → 改 → 再看见 → 再改。** 中间有黑屏、有乱码（Windows 的编码能把中文变成一堆问号）、有打印机卡住不出纸、有代码推送失败十几次。

它真实的样子不是魔法，是耐心。

## 三、安装与第一次打开

**Windows**

1. 到官网/安装包，双击安装（默认路径就行）。
2. 打开后会出现一个对话界面，左边有「新会话」。
3. 第一次用，先做一件事：**建一个专门的工作文件夹**，比如 `D:\我的DSH`。以后所有东西都放这里，别让它在你桌面乱翻。
4. 在这个文件夹里新建一个会话，第一句话可以就是：「我的工作文件夹是 D:\我的DSH，所有文件都放这里，不要动别的地方。」

**macOS**：同样装好，工作文件夹建议放 `~/DSH`，其余步骤一样。

装好之后你会看到几个词，先知道它们大概是什么就行，不用背：

| 词 | 大概意思 |
|---|---|
| 会话（Session） | 一段连续的对话。太长会变慢，做完一件事就开新的 |
| 工作区（Workspace） | 你指定的那个文件夹。它默认在这里干活 |
| 插件（Plugin） | 给界面加功能的扩展。新手可以先不管 |
| 变更 / Diff | 它改文件之前，会告诉你要改哪几行。**一定要看一眼** |

## 四、第一次对话：五句可以直接照抄的话

新手最常见的失败是「不知道说什么」。抄这几句就行：

1. 「我要做一个 ××，给谁看，用来干什么。你先问我三个问题，再动手。」
2. 「先做一个最简单的能跑版，丑没关系，我要先看见它。」
3. 「这个我看不懂，用初中生能听懂的话解释一遍，别用术语。」
4. 「改三处：字号大一点、颜色淡一点、这一块删掉。改完告诉我改了哪几行。」
5. 「把刚才这套做法写成一份说明，放在工作文件夹里，下次我照着做。」

第 5 句特别重要：**让它把经验落成文件**，这样下次不用从头解释。

## 五、第一个练习：30 分钟做一张「每日一页」

这是我最推荐的第一件事，因为它小、有用、当天就能打印。

1. 打开会话，说：「我要一张 A4 的每日计划表，左边写任务、右边留白写备注，一天一页，能打印。」
2. 它会给你一版（大概率难看）。你说：「字号太小，行距大一点，标题加粗。」
3. 说：「再加一个『今天完成了什么』的三行空位。」
4. 满意了就说：「导出成 Word 和 PDF，放到工作文件夹。」
5. 打出来，用一天。**第二天你会立刻发现哪里不对**——这就是最有价值的反馈。
6. 带着具体的问题回去：「第二栏太空，压缩一半；日期要能改。」

走完这一圈，你就懂它 80% 的用法了。

## 六、怎么跟它说话才有效

四条原则：

- **给背景，不给形容词。**「好看一点」它只能猜；「标题 14pt、正文 10.5pt、行距 1.5」它能照做。
- **一次只改一件事。** 一次说十处，它容易改乱，你也不好验收。
- **让它先问。** 加上「先问我三个问题再动手」，能省掉一半返工。
- **不满意就直说。**「这个我不喜欢」「太挤了」「颜色奇怪」——它听得懂人话，也真的会改。

对照表：

| 效果差的说法 | 更好的说法 |
|---|---|
| 帮我做个学习系统 | 帮我做一个能打印的错题本，一页十道，背面答案 |
| 排版好一点 | 标题 14pt 加粗，正文 10.5pt，行距 1.5，段间 6pt |
| 这个不对 | 第三栏太窄，字被挤成两行，加宽到 4 厘米 |
| 随便都行 | 我倾向简单：不要背景图，不要彩色 |

## 七、新手最容易踩的八个坑

| 现象 | 大概原因 | 怎么办 |
|---|---|---|
| 它说改了，但我看不到变化 | 文件被别的程序占用（Word 开着） | 关掉那个文件，让它重新生成 |
| 中文变成一堆问号/方块 | 编码问题（Windows 常见） | 直接说「乱码了，用 UTF-8 重写」 |
| 会话越用越慢、开始胡言乱语 | 对话太长 | 做完一件事就开新会话，把结论写成文件带过去 |
| 它把我别的文件也动了 | 没限定范围 | 一开始就规定「只在这个文件夹里操作」 |
| 页面/程序打不开 | 它改坏了 | 让它「回退到上一步」，或从备份恢复 |
| 打印出来错位 | 打印机缩放设置 | 打印时选「实际大小 100%」，别选「适应纸张」 |
| 一夜之间全乱了 | 一次让它做太多 | 一次一件事，做完验收再下一件 |
| 我不敢让它动我的资料 | 合理 | 先复制一份到工作文件夹，原资料只读 |

## 八、让东西不烂掉的三件小事

1. **一个文件夹，一个规矩。** 所有产物都在工作文件夹；原资料单独放 `资料/`，只读不改。
2. **每次做完，让它写三行记录**：今天做了什么、卡在哪、下次从哪继续。写在 `NEXT.md` 里。
3. **每周备份一次。** 整个文件夹复制到 U 盘或网盘，一分钟的事，能救命。

## 九、安全与边界（认真看这一段）

- 它**真的会改你的文件**。所以：只给它一个文件夹；重要的东西先备份；改之前它会显示「要改哪几行」，**看一眼再同意**。
- **不要**把密码、身份证号、银行卡、别人的隐私贴进去。
- 它有时会**自信地错**。涉及事实、数字、法规，让它给出处，或者你自己搜一下。
- 它**不是人**。你可以把它当工位、当很有耐心的合作者；但情绪上的事，还是得找人。

## 十、三周路线（照这个走不会迷路）

| 周 | 目标 | 具体做 |
|---|---|---|
| 第一周 | 会用 | 每天让它做一件小事：一页表、一段文案、一个清单。学会「说清楚 → 看 diff → 验收」 |
| 第二周 | 能做完整的东西 | 选一个你每天都要重复的事（错题、背词、训练日志），做成能打印的一页 |
| 第三周 | 能维护 | 让它写说明文件、做备份、学会「开新会话 + 带文件过去」 |

三周之后你会发现：**真正稀缺的不是它的能力，是你能不能说清楚自己要什么。**

## 十一、常见问题

**Q：它要钱吗？**
A：有免费额度，重度用会有限制。先用免费的，确认自己真的会用，再考虑。

**Q：我电脑很旧，能跑吗？**
A：能打开就能用，慢一点。它的重活主要在云端。

**Q：我会不会把它用成拐杖？**
A：取决于你让它做什么。让它替你思考，是拐杖；让它替你搬运，是工具。

**Q：它记得我说过的话吗？**
A：同一个会话里记得；跨会话要靠你留下的文件。所以第八节那三件小事很重要。

**Q：别人能看到我的东西吗？**
A：默认在你本机。除非你自己把文件传到网上（比如我做的项目放在 GitHub，那是公开的）。

## 十二、最后，关于「最近不太好过」

我不知道你具体经历了什么，也不打算问。

只说两件我在做事的过程里慢慢确认的事：

**第一，你需要一件「完全属于你」的事。** 不是成绩，不是别人的评价，而是一件你每天能推进一点点、并且只有你能决定它长什么样的东西。我的是那个星图。你的可以是任何东西——一个网站、一份资料、一个游戏、一本册子。DSH 只是让你一个人也能把它做出来。

**第二，找一个人说。** 老师、家里人、信得过的同学，谁都行。这不是软弱，这是把一件超过一个人扛的事，分出去一部分。我见过太多人在这件事上硬撑，撑到最后连「求助」两个字都说不出口。

如果哪天你想动手，告诉我：**你想做一个什么，给谁看。** 剩下的，我们慢慢来。
